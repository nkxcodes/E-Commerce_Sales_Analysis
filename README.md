# E-Commerce Sales and Business Performance Analysis

## Project Overview

This project analyzes e-commerce order data to understand sales performance, product revenue, customer purchasing patterns, and geographical trends. Using Python and data analysis libraries, the project transforms raw order data into meaningful insights that can support business decision-making.

The dataset contains synthetic e-commerce order records from January to April 2026. It is created for learning and portfolio demonstration, not collected from a real company.

## Project Objectives

- Analyze overall revenue and sales volume.
- Identify the highest-revenue products.
- Compare product revenue with sales volume.
- Calculate each category's contribution to total revenue.
- Investigate monthly revenue and order trends.
- Compare revenue and order volume across cities.
- Analyze revenue and order counts by payment method.
- Identify data quality issues and document limitations.
- Present findings through visualizations and a written report.

## Analysis Workflow

### 1. Data Loading and Exploration
Load the dataset and inspect its structure, columns, data types, and summary statistics.

### 2. Data Cleaning
Investigate missing values, duplicate records, invalid values, and inconsistent text formatting.

### 3. Feature Engineering
Create useful columns such as revenue, order month, order year, day of the week, and price band.

### 4. Exploratory Data Analysis
Calculate key metrics and investigate product, category, monthly, geographical, and payment-method performance.

### 5. Data Visualization
Create charts to communicate revenue trends, category performance, top products, and other useful patterns.

### 6. Business Reporting
Summarize findings, limitations, and practical recommendations in a written report.

## Key Business Questions

1. What is the total revenue generated?
2. Which five products generate the highest revenue?
3. Does the highest-revenue product also have the highest sales volume?
4. What percentage of revenue comes from each category?
5. How does revenue change from January through April 2026?
6. Which cities generate the most revenue and orders?
7. Which payment method generates the most revenue?
8. Which payment method is used for the most orders?
9. Is the city with the most orders also the city with the highest revenue?

## Limitations

The dataset is synthetic and covers only January through April 2026. Therefore, its results should not be treated as evidence of real customer behavior or long-term business trends.

Missing or invalid values may affect some metrics. Data quality issues will be investigated and documented before final conclusions are made.
